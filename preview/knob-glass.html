旋钮：液态玻璃珠子（材质 + 灵动 + 水感）

这是 iOS 26 式液态玻璃，不是毛玻璃：没有 backdrop-filter，珠子背后的填充、星尘、 轨道底色是清晰透出来的（毛玻璃会把它们糊掉）。玻璃感全部来自"光在曲面上"—— 珠体只有 .03~.16 的白（几乎空的）、::after 一片大柔光加一枚小亮斑（那一滴镜面光， 位置随档位反向滑 = 滚珠感）、::before 底部一道透射光弧随能量变亮； 形状则由内侧 1px 亮边 + 外侧极细暗发丝 + 两层软投影撑住（浅色轨道上全靠这些）。 下面全是真 CSS + 真几何（抽自 lib/client.js），没有一处手绘。 注意珠子压在填充边界上的那两张 6× 特写：左半边透出档位色、右半边透出轨道灰，边界是锐的 —— 这就是液态玻璃。 最后两张卡片是水感与灵动：填充的液面贴着珠子的后缘走（上限就是珠子右缘 —— 宽度里的 min(0px, …) 保证水不会溢到珠子右边；向后拖时珠子整颗泡在水里， 松手排水还回摆一下）、珠子拖得越快横向拉得越长、落档冲过刻度那一下会"叮"、光慢半拍地跟着晃 —— 那几个数字**同样是现算的**（fillLeadTargetFor / knobStretchFor / knobBounceFor）。

静止：倾角 0 → 水面是**水平的**，且水面在珠子右缘（珠子泡在水里）
向左拖
拖 -400px/秒（= -1.72 pct/秒）→ 倾角 -3.26° ≈ 13.2px 高差（**右端抬起**：水在珠子后侧堆起来）

拖 400px/秒（= 1.72 pct/秒）→ 倾角 3.26° ≈ 13.2px 高差（**右端压下**：水面被推着往前追）

荡波中途的一帧：水面还斜着 -3.40°（≈ 13.8px，反方向荡回来）
